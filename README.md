# Mopux JavaScript

Official TypeScript packages for the [Mopux](https://www.mopux.com) API.

| Package | Description |
| --- | --- |
| [`@mopux/sdk`](packages/sdk) | Client for the Mopux API v1 |

Requires Node.js 24 or 26.

## Development

```bash
npm install
npm test
npm run typecheck
npm run lint
npm run build
```

Releases are published to npm from GitHub Actions when a `v*` tag is pushed.
